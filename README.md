# Supply-chain-profitability-dashboard
An interactive Streamlit dashboard to analyze sales performance, customer segments, product profitability, and discount impact.
##  Key Features
- **Executive KPI's**: Total Revenue, Total Profit, Overall Margin
- **Sales Performance**: Order trends, Top Products, Top Customers, Category breakdown
- **Customer Segmentation**: RFM style segmentation with filters for Revenue, Profit, Margin
- **Discount Impact Analysis**: Compare High-Discount vs Normal-Discount orders on margin
- **Data Visualizations**: Plotly charts, Bar graphs, Scatter plots
- **Filters**: Region, Category, Customer Segment, Discount Rate sliders

##  Tech Stack
`Python` `Streamlit` `Pandas` `Plotly` `Numpy`

##  How to Run
**Streamlit link**: https://supply-chain-profitability-dashboard.streamlit.app
